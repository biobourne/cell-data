# cell-data

HESTA 单文件总览报告（静态站点）。

Read the Docs 从 **`docs/hesta_all_in_one_report.html`** 打包发布。若先把新文件放在仓库根目录，请再执行 `cp hesta_all_in_one_report.html docs/` 后提交。

## 在线文档（Read the Docs）

导入并构建完成后，访问：`https://cell-data.readthedocs.io/`（具体以 Read the Docs 项目设置中的域名为准）。

## 本地预览

```bash
pip install -r docs/requirements.txt
mkdocs serve
```

浏览器打开：<http://127.0.0.1:8000/>
